```bash

```

## Features
- **Universal WhatsApp OTP Auth**: 99.2% deliverability within 2 seconds.
- **Biometric WebAuthn Passkeys**: Touch ID, Face ID, and FIDO2 keys.
- **Adaptive In-DOM Bottom Sheet**: Zero external full-page redirects on mobile web.
- **180 Pay Checkout**: 1-click sovereign 0.8% UPI checkout drawer.
- **RFC 7636 PKCE & RS256 JWKS**: Sub-millisecond local backend token verification.
